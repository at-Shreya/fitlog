# FitLog

FitLog is a responsive workout library and fitness planning web application built with Next.js, TypeScript, and Tailwind CSS. Users can explore different workouts, view detailed workout information, add exercises to today's plan, save workouts for later, and manage their workout list from the My Plan page.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js Image Optimization
- REST API
- LocalStorage

## Key Features

### 1. Workout Library
Browse a collection of workouts with information such as muscle groups, equipment, duration, calories burned, and rating.

### 2. Workout Details
View detailed information for each workout, including description, difficulty, sets, reps, workout instructions, and key specifications.

### 3. My Plan & Saved Workouts
Add workouts to today's plan or save them for later. The My Plan page allows users to switch between Today's Plan and Saved workouts.

### 4. Workout Management
Users can mark planned workouts as done, remove workouts, and receive toast notifications for important actions. The daily workout plan is limited to a maximum of five workouts.

### 5. Sorting & Responsive Design
Sort planned or saved workouts by duration, calories, or rating. The entire application is responsive and works across mobile, tablet, and desktop screen sizes.

## Project Highlights

- Responsive dark-themed fitness interface
- Dynamic workout data fetched from an API
- Custom 404 page
- Loading animation while workout data is being fetched
- Toast notifications for user actions
- Persistent workout plan and saved workouts using LocalStorage
- Mobile-friendly navigation and layouts
